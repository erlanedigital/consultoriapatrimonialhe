## 💎 Sobre o Projeto

Aplicação web desenvolvida para a consultoria de **Erlane Mota** (@erlane.engenhariafinanceira), especialista em Engenharia Financeira e Planejamento Patrimonial. O foco principal é demonstrar de forma clara e visual como pessoas que não receberam herança por nascimento podem construir sua **própria herança em vida** através de consórcios imobiliários inteligentes, parcelas reduzidas até a contemplação e estratégias de ágio ou renda passiva de aluguel.

### 🌟 Destaques & Diferenciais

- 🏡 **Oferta em Destaque:** Carta de crédito de R$ 100 mil com parcela reduzida de R$ 337 até a contemplação.
- 🎛️ **Simulador Interativo em Tempo Real:** Slider dinâmico de R$ 80 mil a R$ 1 milhão com recálculo instantâneo de parcela, ágio estimado e renda passiva de locação, integrando direto com o WhatsApp da Erlane.
- 📑 **Estratégias Interativas:** Abas dinâmicas para *Estratégia do Ágio/Lucro*, *Estratégia do Aluguel* e *Consórcio + Renda Fixa*.
- ❓ **FAQ Acessível com Accordion:** Todas as dúvidas frequentes respondidas com clareza.
- 📸 **Fotografias Exclusivas em Alta Definição (HD/WebP):** Sem repetição de fotos no site.
- 🛡️ **Segurança Bancária & LGPD:** Cabeçalhos HSTS forçado (`max-age=63072000`), CSP, X-Frame-Options e conformidade total com a LGPD.
- 🔐 **Painel Administrativo Blindado:** Bloqueio anti-força bruta de 15 minutos após 5 erros consecutivos de senha, modal de alteração de credenciais e encerramento de sessão.
- ⚡ **Deploy Global na Cloudflare Workers & Pages:** Publicado na CDN da Cloudflare com cache otimizado.

---

## 🚀 Como Executar Localmente e Fazer Deploy

```bash
# 1. Compilar para a pasta dist/
npm run build

# 2. Deploy para Cloudflare Workers (consultoriapatrimonialhe.emia.workers.dev)
npm run deploy

# 3. Deploy para Cloudflare Pages
npm run deploy:pages
```
